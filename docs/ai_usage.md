# AI Usage and Disclosure

## Tools used and areas of assistance

The project used the following AI-assisted tools:

- **Claude (Anthropic, claude.ai):** design discussion, code-generation assistance, and code review during project development.
- **ChatGPT (OpenAI):** review and feedback on the project and its technical submission materials.
- **GitHub Copilot:** assistance with smaller implementation tasks and code generation.
- **GitHub Copilot SDK in VS Code:** repository inspection and targeted documentation, test, and reproducibility improvements during a later review.

AI assistance contributed to drafts or revisions involving the data model, synthetic-data generator, validation rules, model pipeline, export tooling, tests, and documentation. The project did not maintain a complete phase-by-phase or line-by-line authorship log. This disclosure therefore does not imply that every line was generated by AI, nor that every AI-suggested change was accepted unchanged.

## Prompt records

The [`prompts/`](../prompts/README.md) directory contains selected prompt records and related implementation notes for schema design, validation, evaluation, and repository review.

These files are **not a complete export of every AI conversation**. Some earlier prompts and responses—particularly from the initial Claude-assisted development—were not retained. Where an implementation note or outcome summary appears beside a prompt, it is labelled separately and should not be read as part of the original prompt text. No missing prompt transcript has been recreated or presented as verbatim history.

The tool and date associated with each individual prompt were not consistently recorded. They are therefore left unspecified rather than inferred.

## Human responsibility and review

AI output was used as assistance, not as an authority. The project owner remains responsible for the submitted code, data-generation assumptions, business rules, validation results, model interpretation, and documentation.

Before submission, the project owner should be able to explain the implementation and should independently verify the generated data, tests, temporal evaluation, leakage checks, and limitations. The repository does not claim that every AI-generated suggestion received a separate line-by-line review.

## Data handling and intended use

No real employee or candidate data was supplied to AI tools. The workforce records in this repository are synthetic. No external dataset is used; see [`source_manifest.md`](source_manifest.md) for provenance.

The model is a synthetic decision-support demonstration intended only to help prioritize supportive retention conversations. It must not be used to make or automate hiring, promotion, compensation, performance-management, termination, or other employment decisions. Any real-world use would require appropriate legal, privacy, security, validity, and fairness review, as well as meaningful human oversight.

## Validation and reproducibility

The repository contains automated tests, data-validation rules and reports, model-evaluation and leakage-audit reports, and reproducibility scripts/reports. These artifacts document the checks associated with the repository version from which they were produced.

A fresh-clone verification is not claimed by this disclosure unless it has been performed separately. For the commands and expected workflow, see the project README.
