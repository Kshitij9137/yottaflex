# AI Usage

## Tools and contributions

Project records identify Claude (Anthropic), used through claude.ai for design
review, code generation, and code review. AI assistance also contributed drafts
of the generator, validation rules, model pipeline, export tooling, tests, and
documentation. The phase-by-phase and line-by-line authorship was not tracked,
so this disclosure does not claim that every generated change was independently
reviewed.

The project owner is responsible for reviewing the synthetic-data assumptions,
business rules, model limitations, and any decision to use the outputs. The
model is intended only to prioritize supportive conversations and must not
automate employment decisions.

## Validation and limitations

The repository includes tests, validation reports, and reproducibility reports
as evidence of the checks that were run. A fresh-clone review is not claimed
here. No real employee data was supplied to AI tools; all project data is
synthetic. See [the source manifest](source_manifest.md) for provenance.
