# Prompt Records

This directory contains **selected prompt records** and implementation notes retained for the YottaFlex synthetic workforce-retention project.

It is intended to make the use of AI assistance more transparent. It is not a complete conversation archive or a claim that every AI interaction has been preserved.

## Contents

| File | Subject | What it records |
|---|---|---|
| [`schema_design.md`](schema_design.md) | Relational model and history design | Two schema-design prompts and notes about the design choices subsequently adopted |
| [`validation_framework.md`](validation_framework.md) | Data-quality validation | A validation-checklist prompt and a separate note describing the repository's validation coverage |
| [`evaluation_design.md`](evaluation_design.md) | Temporal evaluation and metrics | Prompts about chronological evaluation and imbalanced-class metrics, with implementation notes kept separate |
| [`review.md`](review.md) | Repository review | The detailed review request and assignment criteria retained in the project |

## Record conventions and limitations

- Prompt text is presented as retained in the project files; do not assume it is a complete transcript of the original AI conversation.
- Implementation/outcome notes are explicitly labelled and are not represented as AI responses or verbatim prompt text.
- Tool names and dates are included only where they were recorded. Missing metadata is not guessed.
- Some earlier Claude-assisted prompts and responses were not retained. They have not been reconstructed.
- AI responses are not required for this prompt-record index and are not included as a complete response archive.

For the overall tools disclosure and the project's human-review and data-handling responsibilities, see [`docs/ai_usage.md`](../docs/ai_usage.md).
